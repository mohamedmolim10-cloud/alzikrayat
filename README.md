# Project Name
Alzikrayat (الذكريات) - Photo Sharing Web Application

## A Simple Description
Alzikrayat is a lightweight, responsive photo-sharing platform developed from scratch without any external frameworks or ORMs. It allows users to register, log in, browse a collective gallery, upload high-resolution images with titles and descriptions, view detailed photo pages, and engage via comments. The system strictly adheres to a native 3-Tier Physical Architecture and the Model-View-Controller (MVC) architectural pattern.

## Technologies
- Backend: Native PHP (OOP, PDO)
- Database: MySQL (Enforcing Referential Integrity & Cascade Delete)
- Frontend: HTML5, CSS3, JavaScript (ES6), Bootstrap 5 (RTL Support), FontAwesome
- Routing: Custom Manual Regex-based URL Router
- Web Server: Apache (XAMPP Environment)
- Version Control: Git & GitHub
